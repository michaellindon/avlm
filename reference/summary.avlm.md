# Summary Method for Anytime-Valid lm (avlm) Objects

Computes a summary for an `avlm` object, a linear model enhanced with
anytime-valid inference. In addition to the standard `lm` summary
statistics, the p-values for the coefficient tests are recalculated
using an anytime-valid method.

## Usage

``` r
# S3 method for class 'avlm'
summary(object, ...)
```

## Arguments

- object:

  An `avlm` object generated by `av.lm`.

- ...:

  Additional arguments passed to or from other methods.

## Value

A summary object of class `summary.avlm` that includes updated p-values
for the coefficients.
